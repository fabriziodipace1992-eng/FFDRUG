Configura Scottino

Per usare l'intelligenza artificiale serve una chiave API di Anthropic.
La chiave viene salvata solo in questo browser, mai online.

Come ottenerla (5 minuti):

  1. Vai su console.anthropic.com
  2. Registrati o accedi
  3. Menu a sinistra → API Keys
  4. Clicca Create Key, copia la chiave
Chiave non valida o errore di connessione. Controlla e riprova.

Salvata solo nel browser (localStorage). Non viene mai inviata ad altri server.
